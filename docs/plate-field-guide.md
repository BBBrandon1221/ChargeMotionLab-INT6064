# INT6064 第四模块：平行板电场偏转靶场

**一句话**：上下两块平行极板之间是匀强电场，电子流从下板往上板跑，左侧射入一个带正电的小球被电场压向下板 —— 学生调四个参数，想办法让它落在靶心上。

前三站（课时 1–3）全是纯磁场：洛伦兹力不做功、速率不变。这一站是**电场**：力做功、速率一路在变。摆在一起正好构成对照，这是它进这套东西的理由，不只是"多加一个游戏"。

---

| 做什么 | 怎么做 |
|---|---|
| 走进去 | 大厅里 WASD 走到 **④ 电场偏转靶场**，左键点舱体 |
| 直接进（演示用） | `ChargeMotionLab.exe -starthub -enterlab -enterstation 4` |

| 截图/出图专用 | 加 `-platefire` 进站 1.2 秒后自动发射一次；再加 `-plateparams U,q,m,v0` 可指定参数，例如 `-plateparams 40,1,1,4.8` |

## 二、屏幕上每个东西是什么

| 元素 | 含义 |
|---|---|
| 红色横条（上） | 上极板 = 正极 |
| 蓝色横条（下） | 下极板 = 负极 |
| 蓝色竖箭头 ↓ | 电场方向，由 + 指向 − |
| 青色小点（6 列，往上跑） | 电子流。电子带负电，所以**逆着电场走** |
| 黄色小球 | 带正电的粒子，从左侧发射口水平射出 |
| 黄色实线 | 已经飞过的轨迹 |
| 灰色细线 | 按当前参数算出来的预测轨迹（`G` 键可关） |
| 绿色横段 | 靶心（宽 1.1），打中判命中 |
| 两段琥珀色横段 | 「别的位置」，用来对照 |
| 右上白色卡片 | 参数表：电压 U / 电荷量 q / 质量 m / 初速度 v₀ |

按键：`空格` 发射 · `R` 复位 · `N` 换靶 · `G` 开关预测线 · `Esc` 返回大厅。

### 结算弹窗（左上角）

小球停下来的那一刻弹出，一次只显示一张，动任何参数就消失：

| 情况 | 标题色 | 标题 | 副行给的建议 |
|---|---|---|---|
| 打进绿区 | 绿 | 命中靶心 | 命中 N / 试射 M · 按 N 换一个新靶 |
| 离靶心 ≤1.15 | 琥珀 | 擦边：离靶心 0.78 m | 把 v₀ 或 U 再挪一格 |
| 落在靶外、偏**右** | 红 | 偏右 1.58 m，没进绿区 | v₀ 太大，球还没落下就飞过去了 → 把 v₀ 调小，或把 U / q 调大 |
| 落在靶外、偏**左** | 红 | 偏左 1.21 m，没进绿区 | 偏转过头了 → 把 v₀ 调大，或把 U / q 调小 |
| 撞上板 | 红 | 撞到上极板了 | 把 U 或 q 调小，或把 v₀ 调大 |
| 从右侧飞出 | 红 | 从右侧飞出去了，没打到板 | 偏转太弱 → 把 U 或 q 调大，或把 v₀ 调小 |

左右两种失败的**建议是相反的**（偏右=太快、偏左=偏过头），所以文案分开写，不是一个通用句。

## 三、四个参数是怎么起作用的

极板间距 d = 4.4，板长 6.4，小球从 y = 0 的高度进入板间，要落到 y = −2.0 才算贴到下板。

```
E = U/d          a = qE/m = qU/(md)
t = √(2Δy / a)   Δy = 2.0
落点 x = −3.2 + v₀·t
```

实测算出来的落点（和程序里完全一致，可以用来对答案）：

| U | q | m | v₀ | 加速度 a | 结果 | 落点 x |
|---|---|---|---|---|---|---|
| 40 | +1 | 1 | **7.2** | −9.09 | 打下板 | **+1.58**（默认值，故意打偏） |
| 40 | +1 | 1 | 4.8 | −9.09 | 打下板 | −0.02（正中靶心） |
| 40 | +1 | 1 | 6.0 | −9.09 | 打下板 | +0.78 |
| 40 | +1 | 1 | 3.0 | −9.09 | 打下板 | −1.21 |
| 20 | +1 | 1 | 4.8 | −4.55 | 打下板 | +1.30 |
| 60 | +1 | 1 | 4.8 | −13.64 | 打下板 | −0.60 |
| 40 | +2 | 1 | 4.8 | −18.18 | 打下板 | −0.95 |
| 40 | +1 | 2 | 4.8 | −4.55 | 打下板 | +1.30 |
| 40 | −1 | 1 | 4.8 | **+9.09** | 打**上**板 | −0.02 |
| 0 | +1 | 1 | 4.8 | 0 | 直线飞出 | — |

**默认参数为什么是「打偏」的**：v₀ 默认 7.2，落点 +1.58，绿靶在 0 —— 第一次发射必定失败。这是有意的教学设计：先让学生看到失败，才有动机去改参数；一进站就看到「命中」，这个操练就没有存在意义了。把 v₀ 拖到 ≈4.8 才进绿区。

两件事可以直接当结论讲：
- **q 翻倍 和 m 减半效果完全相同**（a 只认 q/m）。
- **电荷反号，偏转方向立刻反过来**（打下板 → 打上板）。

## 四、三个 60 秒演示（课堂直接用）

**① 标准剧本：先失败，再调中（一进站就能照着做）**

1. 进站直接按 `空格`。落点 +1.58，弹窗红字「偏右 1.58 m，没进绿区」，副行写着"球太快，还没落下就飞过去了"。
2. 指着灰色预测线说：*现在它指着靶子右边，我们把它拉回来。*
3. 把 v₀ 从 7.2 拖到 4.8。灰线当场收进绿靶 —— 这时**先别急着发射**，问一句"你们觉得会中吗"。
4. 按 `空格`。绿色弹窗「命中靶心」。
5. 再把 v₀ 拖到 3.0 发射：落点 −1.21，弹窗变红字「偏左 1.21 m」—— 太快会偏右，太慢会偏左，只有一个值能中。

**只动初速度 v₀：3.0 → 4.8 → 6.0**
落点 −1.21 → −0.02 → +0.78，一条线扫过整个靶区。
要说的话：*电场给的是固定的向下加速度，球飞得越慢，被拽下去的时间越长，所以落点越靠左。*

**② 只动电压 U：20 → 40 → 60**
落点 +1.30 → −0.02 → −0.60，纯"偏转力度"。
要说的话：*电压不改变落点的规律，只改变"拽得有多狠"。*

**③ 把 q 改成 −1，再按空格**
球直接撞上板。再把 U 调到 0 —— 球一条直线飞出去，什么也不发生。
要说的话：*这就是电场和磁场最不一样的地方：磁场只改方向、不改快慢；电场会把东西加速、也会把东西刹住。*

**先猜后验的玩法**：开讲前按 `G` 关掉灰色预测线，让学生先喊"往哪偏"，再按空格。

## 五、物理口径（避免被问住）

- **只算电场力，没有重力**。板外没有场，所以小球飞出极板后就按出射速度直线走。
- 板间是匀强场 → 加速度恒定 → 轨迹是**精确抛物线**，程序里不积分，直接解析求解，所以落点和公式永远一致。
- 电子流方向和电场方向相反，是因为电子带负电；正电小球被压向下板，二者方向恰好相对 —— 这是有意留下的对比，不是画错。
- 靶外那两段琥珀色只是参照物，**不计分**，命中只认绿色靶心（半宽 0.55）。

## 七、要改的话改哪里

| 想改什么 | 改哪里 |
|---|---|
| 极板大小 / 间距 / 发射位置 | `PlateFieldModule.cs` 顶部 `HalfSpan / Gap / LaunchX / TargetHalf` |

```
Unity.exe -batchmode -quit -projectPath <工程> -executeMethod BuildWin.Build -logFile build.log
```

# 第四站（默认）：粒子导航员 · 把粒子送进接收器

**一句话**：匀强磁场里，带电粒子只会被洛伦兹力"掰弯"——速率不变、轨迹是圆周。学生用这条规律，选方向、调半径、自己设计路线，把粒子送进墙上的绿色接收器。

这一站对应课程小组项目里负责的部分：

> 在 Unity 现有 Boris 求解器上实现第四台挑战（"粒子导航员：将粒子送入接收器"），三关递进 + 预测后发射 + 前后轨迹对比。
>
> - 第一关：选对方向。固定速度与角度，只选择磁场向里或向外，理解转向。
> - 第二关：调出合适半径。固定方向和角度，只调初速或磁场强度，理解比例关系；判定位在第一关基础上收窄。
> - 第三关：路径规划。场地由三段不同磁场（⊙1.1 / ⊗1.0 / ⊙1.2）拼接，学生调初速 `v` 与发射角，让粒子依次穿过 ①②③、最后落入下壁接收器；命中后可尝试另一种解。

> 交付物对照：**可运行包**（随工程打包）· **成功/失败参数**（本文第三、五节）· **测试结果**（第六节，`-autotest` 可复现）· **演示素材/1.5 分钟现场操作**（第七节）· **退出无状态残留**（`HideModule` 只关根节点，重进即新局）。

## 三、三关怎么设计

### 第一关 · 选对方向

- **锁定**：`v = 3`、发射角 `0°`、`|B| = 1`；只能点 **⊙ 向外** 或 **⊗ 向里**（或按 `B`）。
- **接收器**：下壁 `x = -5.76`，半宽 `0.80`（很宽，只考方向）。
- **默认是错的**：开局磁场向里，弧线向上撞上壁——第一次发射必定失败，学生才会主动去翻方向。
- **正确解**：切到"向外"，正电荷顺时针向下弯，落进下壁接收器。

### 第二关 · 调出合适半径

- **锁定**：方向固定"向外"、发射角 `0°`；可改初速 `v` 或磁场强度 `B`。
- **接收器**：下壁 `x = -4.13`，半宽 `0.28`（在第一关基础上收窄，考"半径要刚好"）。
- **默认打不中**：`v = 3` 的落点是 `-5.77`，偏左 1.64 m。
- **正确解**：把 `v` 调到 `≈4.0`，或把 `B` 调到 `≈0.75`。两者都在改 `r = mv/(qB)`，这正是比例关系的教学点。

### 第三关 · 路径规划（三段拼接磁场）

- **场地**：沿 `x` 分成三段「拼接磁场」，分界在 `x = -5` 与 `x = -1`；三段方向交替、强度不同 —— `① ⊙1.1 / ② ⊗1.0 / ③ ⊙1.2`（每段上方标了 ⊙/⊗ 与强度）。
- **开放**：初速 `v ∈ [2, 7]`、发射角 `θ ∈ [-30°, 30°]`；三段磁场由系统固定，不由学生调。
- **接收器**：固定在**下壁**，`x ∈ [-0.8, 0.7]` 随机、半宽 `0.50`；初始 `v = 2.6` 故意打偏。
- **按顺序穿过**：必须依次穿过 ①②③ 三段，最后落入下壁接收器；三个检查点环会随粒子在 1→2→3 依次点亮。若整条轨迹没进到第三段（例如提前撞墙），判为「路线不完整（Route incomplete）」，而不是普通撞错墙。
- **玩法**：拖 `v` / `θ`，看灰色预测弧线依次扫过三段、落入接收器，再按空格。命中后可换一组参数找**另一种解**；按 `N` 换一个新目标。
- 已用离散积分穷举验证：该随机范围内每个目标都有大量 `(v, θ)` 组合能命中（见第五节样例）。

## 四、物理与几何（防止被问住）

粒子质量 `m = 1`、电荷 `q = +1`，磁场垂直纸面 `B = Bz·ẑ`。洛伦兹力 `F = q v×B` 只改方向、**不做功**，所以速率恒定、轨迹是圆：

```
r = mv / (|q| B) = v / B
```

- `⊙ 向外`（`Bz > 0`）：正电荷**顺时针**转，从 `+x` 射入时向下弯；
- `⊗ 向里`（`Bz < 0`）：正电荷**逆时针**转，向上弯。

第一/二关发射角 `0°`，从上壁 `y = +5` 或下壁 `y = -5` 的落点满足：

```
圆心 (-8, ∓r)，圆 (x+8)² + (y±r)² = r²
代 y = -5  →  (x+8)² = 10r - 25
落点 x = -8 + √(10r - 25)        （r ≥ 2.5 才碰得到下壁）
```

程序里不解析求解、也不调 `Solve()` 生成几千帧，而是用现有 **Boris 积分器**（`SimulationSolver.BorisStep`，与九个磁场算例同一套数学）逐步推进，步长 `dt = 0.004`；撞墙时在线段上按比例插值。离散积分与解析落点相差约 1 cm，远小于第二关 `0.28` 的半宽。

## 五、成功 / 失败参数表

### 第一关

| 3.9 | 1.00 | -4.27 | 0.14 m | 在 0.28 内 → 命中 |

## 六、自检结果（`-autotest` 可复现）

`ChargeMotionLab.exe -autotest out.txt` 末尾会多出一段：

```
=== 第四站 粒子导航员：Boris 圆周导航自检 ===
r=3.0  解析落点 x=-5.764  数值 x=-5.770  差 6.0 mm  OK
r=4.0  解析落点 x=-4.127  数值 x=-4.135  差 8.0 mm  OK
r=5.0  解析落点 x=-3.000  数值 x=-3.010  差 10.0 mm  OK
方向翻转：向外→bottom  向里→top  OK
半径单调：v=3 落点 -5.77 → v=6 落点 -2.09  OK 半径变大、落点右移
能量守恒：|v| 3 → 3.000000  漂移 6e-15  OK 磁场力不做功
第一关：接收器 bottom x=-5.76（半宽 0.80）  v=3.0  B=1.00  向外=False
第二关：接收器 bottom x=-4.13（半宽 0.28）  v=3.0  B=1.00  向外=True
第三关：接收器 bottom x=…（半宽 0.50）  v=2.6  B=1.00  向外=True
第三关默认射击：maxX=-5.64 判定=MissRoute  OK 需要自己规划路线
```

前五项是判据：解析落点、方向翻转、半径单调、能量守恒（磁场不做功）；末尾一行校验「不规划、直接默认射击应被判为路线不完整（MissRoute）」。中间几行是每关默认参数。

## 九、和三关磁场课时 / 平行板靶场的关系

- 前三站（课时 1–3）是**看懂**磁场：同种/异种电荷、控制变量、未知粒子。
- 这一站是**用**磁场：把 `r = mv/(qB)` 当成设计工具，自己把粒子导航到目标。
- 平行板靶场（`-plate`）是**电场**：力做功、速率一路变，和这里的"速率不变"正好对照。两套模块都保留，答辩时可一句话对比"磁场只改方向、电场也改快慢"。
